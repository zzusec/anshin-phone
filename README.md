# 安心手机

面向老人使用的 Android 手机整理工具：日常只需“一键优化”，保留常用软件，清理结果可查看、安装包可恢复。家人协助是备用功能，不是正常操作的前提。

**当前版本为公开测试版，不是病毒扫描器，也不能保证拦截所有广告。**默认不 root、不刷机、不改系统分区。支持 Android 9 及以上；首先针对华为 Android 9 适配。其他品牌的未知系统包默认保护，不盲删。

## 下载与手机更新

从 GitHub Releases 下载最新版 APK。应用内“设置 → 软件更新”可检查、下载更新；安装前校验 SHA-256、包名、版本和签名。更新不清除工具现有记录，Android 系统可能仍要求确认安装。

首次安装需要完成一次电脑初始化；后续日常不需要填写包名、规则或服务地址。此仓库不包含签名私钥或个人设备数据。公开测试版沿用维护者的同一测试签名；发布版签名切换若发生，会另行说明，不能绕过签名检查。

## 功能

- **一键优化**：按不可修改的核心保护＋用户可修改的常用软件白名单处理。微信、支付宝、百度、高德、抖音、快手等默认保留。
- **看清结果、恢复软件**：显示实际卸载的软件，有完整备份时可单项／一键恢复。只恢复安装，不保证恢复卸载丢失的聊天、账号或其他私有数据。
- **广告防护**：本机 DNS-only 过滤与允许名单。默认从 GitHub `StevenBlack/hosts` 获取广告／恶意域名列表，系统调度联网每天更新；失败保留上次有效规则。系统省电限制可能延后更新。
- **临时家人协助**：手机发起一次性邀请，批准后才允许查看清单，每批清理还要确认。可撤销、会话到期失效；不开放任意 Shell 或公网 ADB。
- **手机更新**：仅从本仓库正式 Release 获取更新，核验完整性和原签名后交给系统安装。

## 一次电脑初始化

先在手机开启 USB 调试，并确认当前电脑的调试授权。电脑需 Node.js 22+、ADB：

```sh
npm ci
npm run build
node scripts/adb-setup.mjs --apk artifacts/你下载的安装包.apk
```

只有一台设备时自动识别；多台设备可在电脑端使用 `--serial` 指定，不在老人界面显示技术选项。脚本只初始化本工具、启动 UID2000 的窄接口助手；不执行清理。

默认协助地址为 USB 本机调试模式 `http://127.0.0.1:8787`，脚本启动电脑中转并建立 `adb reverse`。**它不是公网链接**，拔掉 USB 或关闭电脑会失去此协助连接。若有自己的 HTTPS 中转服务，使用：

```sh
node scripts/adb-setup.mjs --apk artifacts/安装包.apk --server-url https://你的协助服务域名
```

不需要老人填写地址。手机重启或系统终止 shell 助手后，高级清理可能需要重新连接电脑初始化；不谎称 Android 9 无 root 可以永久维持该权限。

## 开发与构建

```sh
npm ci
npm run build
npm test
npm start
```

默认服务仅监听 `127.0.0.1:8787`。网页在没有手机原生桥时明确显示界面预览，不会假清理。服务实现及 HTTPS 配置见 `server/README.md`。

Android：JDK17、SDK35、Gradle wrapper8.7：

```sh
export JAVA_HOME=你的JDK17目录
export ANDROID_HOME=你的AndroidSDK目录
android/gradlew -p android --no-daemon assembleDebug testDebugUnitTest
```

构建用 Preline UI/Tailwind，本地编译至网页与 APK，不用 CDN、外部字体或第三方分析。第三方许可见 `web/THIRD_PARTY_NOTICES.md` 和随产物附带的 `PRELINE-LICENSE.txt`。

## 必须知道的边界

- 用户级移除预装包不会物理删除系统原始 APK；系统/厂商限制可能阻止某些操作，失败会明示。
- APK 备份不包含个人数据。一键恢复只处理本工具记录且备份完整的项目。
- DNS 过滤不覆盖同域广告、已缓存内容、应用自带 DoH/DoT、硬编码 IP、所有弹窗或全部 IPv6/TCP DNS。
- 不替换正在使用的其他 VPN，不安装 HTTPS 解密证书，不自动开启无障碍。
- 远程认证、清理权限和 Android 系统授权是不同边界；链接不能绕过手机确认。
- CI/单测/浏览器模拟不等于在每个品牌手机上验证成功。请先保留常用软件，再在可控范围使用测试版。
