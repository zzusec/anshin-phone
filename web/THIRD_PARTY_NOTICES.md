# UI third-party notices

The interface uses Preline UI 5.0.0 (Preline Labs Ltd., MIT and Preline UI Fair Use License) and Tailwind CSS 4.3.0 (MIT). Preline's CSS variants, component utility patterns, and JavaScript accordion initialization are locally compiled into the web application and Android assets. The complete installed Preline license is shipped as `PRELINE-LICENSE.txt` in both outputs. No paid Preline Pro assets are used. No runtime CDN, external font or analytics is loaded.

Our application is a phone-assistance product, not a UI component library competing with or republishing Preline UI. Upstream files remain unmodified in node_modules and package-lock.json locks the build inputs.
