# 项目计划：安心手机

更新：2026-10-04。项目目录：`/Users/hx10/android-cleanup`。

## 1. 目标与用户

帮助老人清理手机中的非核心软件，降低恶意软件、推广弹窗和诱导安装的风险；子女可以从网页发起经老人手机明确批准的临时远程协助。第一适配对象是华为 GLK-LX1U、Android 9 / EMUI 9.1，后续其他品牌按能力及适配名单扩展。

这是手机产品。目录里的电视清理是临时历史任务，不继续开发电视功能，不将 API19、电视 root 或卸载结论套给手机。

## 2. 三项功能

### 手机清理
- 扫描当前用户应用，分类：核心、确认可清理预装、第三方、未知系统包。
- 保护电话/短信/联系人、当前桌面/输入法、设置、网络、权限管理、安全更新、关键服务及自身协助组件。
- 核心名单由基础保护项＋机型版本适配＋运行时默认应用共同决定；不能仅用 SYSTEM 标志或应用名称判断。
- 核心以外已确认可处理的软件可全选，家庭也可明确保留必需应用。未知系统包暂不自动删除。
- 删除前说明数据损失，备份并校验 base/split APK；APK 备份不是聊天/照片/账号数据备份。
- 普通权限调用系统卸载确认；可选 Shizuku UserService 使用窄接口进行用户级移除。默认不保留目标应用数据，不默认 root、刷机、改系统分区。
- 逐项核验当前用户安装状态；失败可定位，停用/仅提交请求不能标为已卸载。
- 恢复区分预装注册和普通 APK/split 安装；不保证恢复卸载丢失的数据。

### 子女远程协助
- 老人主动创建一次性邀请；子女填写可识别称呼领取；手机确认后才分享应用清单和允许提交任务。
- 默认会话30分钟；手机可随时撤销。链接只是领取凭证，不是执行授权。
- 首版手机助手保持前台轮询；不做隐藏式无人值守控制。超过30秒未收到有效设备心跳，不允许新任务并显示离线。
- 每批远程清理还需在手机确认名单及数据损失；设备端再次保护核心，不依赖网页禁用按钮。
- 只开放清理命令，不开放任意 Shell、公网 ADB、短信/私人文件浏览、完整远程桌面。
- 生产公网需要用户自己的 HTTPS 地址与部署授权；未具备时交付本机可跑服务及部署文档，不虚构可外网访问的链接。

### 广告与诱导防护
- 本地 DNS-only VPN 过滤有限广告域名，允许名单优先，可关闭、可观察误拦。
- 只处理经虚拟DNS的IPv4 UDP/53 A/AAAA查询；不接管全部流量，不解密HTTPS，不保证应用内/同域/缓存/自带DoH广告被过滤。
- 已有VPN使用中明确拒绝启动过滤，不能悄悄替换Clash等已有连接。
- 没有可用上游或网络发生变化，停止/报错，不静默改用别的DNS。停止及撤销后资源和状态一致。
- 营销通知、悬浮窗、安装未知应用、无障碍、设备管理员提供可操作的系统权限引导；普通助手不能做到的静默撤权必须如实说明。
- 按机型提供厂商推广设置/独立非核心广告组件处理；不为去广告删除核心包。

## 4. 技术路线

| 部分 | 当前选择 |
|---|---|
| Android | Java、minSDK28、compile/target SDK35、AGP8.6.1/Gradle8.7/JDK17 |
| 手机界面 | WebView加载打包的本地HTML/CSS/JS，严格隔离本地源与原生桥 |
| 高级清理 | Shizuku API/provider 13.1.5，UserService固定命令，无newProcess或任意shell |
| 广告过滤 | 自研小型Java DNS解析/规则与VpnService；不复制GPL/AGPL实现代码 |
| 子女端 | 原生ES模块网页，无外部CDN/字体/第三方追踪 |
| 中转 | Node22原生HTTP、内存会话、哈希凭证、状态机、限流；零运行时外部依赖 |

参考开源产品和许可证见 `docs/open-source-research.md`。不能把AYA理解为现成手机端或网页远控服务器。重用代码、数据名单或协议时必须核对对应许可证并保留声明。

## 5. 实施顺序

### P0：可构建、契约一致、安全阻塞清零
修AIDL，生成并校验APK；统一时间/phase/应用字段/批量上限；完成高风险审查与对应回归测试；让手机桥和中转实际联通。

出口：整包构建和单测通过，演练邀请→领取→批准→任务→逐包结果，无核心删除绕过，无假成功。

### P1：手机本地清理闭环
扫描、保护、选择、数据确认、备份、普通卸载/Shizuku卸载、结果核验、恢复；处理取消、权限失效、进程/Activity生命周期。

出口：在经授权的测试设备上验证完整闭环，不能用启动Intent作为卸载成功证据。

### P2：远程协助闭环
会话批准、邀请一次性、到期/撤销/离线、任务批准/拒绝/取消、鉴权隔离、断网结果同步、隐私与部署说明。

出口：两端端到端测试通过；HTTPS跨设备实测另记，不具备环境时明确未执行。

### P3：广告防护闭环
DNS请求实测、NXDOMAIN/SERVFAIL、误拦允许、已有VPN保护、网络切换/关闭/重启、权限引导；不能只测规则字符串。

出口：确认普通网络不被全路由接管、VPN关闭资源清理、无伪全广告拦截。

### P4：老人易用性与交付
按参考图完成手机/桌面浏览器检查，375px与放大字体、读屏、错误和返回路径；提供APK、启动/配置文档、许可证、验证记录和限制。

出口：逐条核对 `docs/ACCEPTANCE.md`，交付时区分通过、未执行和阻塞，不靠服务启动/代理报告宣称全部完成。

## 6. 不做与需要另行授权的操作

不改YOLO模式、wrapper、AgentGuard/TermYes；不打印账户API密钥；不自动公网部署、创建付费资源、推送代码或上传设备记录。没有用户额外明确许可，不对现有手机进行实际卸载、安装、root、重启、刷机或修改安全设置。
