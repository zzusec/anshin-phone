# 验收标准

更新：2026-10-04。每项最终标为：通过 / 失败 / 未执行（原因）。测试必须验证行为，不只匹配UI文字。

## A. 构建与自动化（发布阻塞）
- [ ] `npm run build`生成子女网页及Android内置同版本资源，不能漏文件或使用旧产物。
- [ ] `npm test`全通过，现有43项不能弱化或删除以掩盖回归。
- [ ] JDK17 + SDK35完成 `assembleDebug testDebugUnitTest`；AIDL、Java、资源、manifest、DEX均通过。
- [ ] APK位于 `artifacts/`，能用aapt/apksigner检查包名、minSDK、权限、版本、签名；记录SHA-256。
- [ ] Android9依赖和运行库API兼容，不把Java17构建机能力等同手机运行库；纯Java测试不冒充Android运行测试。
- [ ] 生成物、测试日志、私密执行日志不混入源码发布。

## B. 清理正确性与数据边界
- [ ] 默认桌面、输入法、电话/短信/联系人、网络、更新安全组件、自身协助包不可选；直接构造请求也会被设备和服务拒绝。
- [ ] 未确认系统包不可自动处理；适配名单限定机型/版本，不以“非系统/含广告名”为恶意判定。
- [ ] 可全选已确认非核心项，也可明确保留；不得默认为用户保留所有个人App而偏离需求。
- [ ] 本地和远程删除前明确目标及私有数据损失，未确认则无删除。
- [ ] 备份含base及全部split，大小/hash一致；空间不足、复制/CRC/hash失败时不删除。
- [ ] 普通卸载拒绝/取消/设备管理阻止，真实记为未完成；当前用户安装状态核验后才能记成功。
- [ ] Shizuku未启动、拒绝、Binder死亡、超时、系统拒绝均可见；默认不保留数据，不物理改系统分区。
- [ ] UserService仅允许固定操作/严格包名/指定用户；校验调用UID、运行时核心与当前用户；不暴露任意Shell。
- [ ] Activity关闭/旋转/进程死亡/返回/多批并发不产生重复或越权卸载。
- [ ] 恢复核验APK备份或预装注册；包括split恢复、用户取消、旧数据不可恢复提示。
- [ ] 从已有`-k`用户卸载过的应用，不能重复不带-k命令就声称清除了旧数据。

## C. 远程协助安全与闭环
- [ ] 全端采用一份明确DTO/状态机；ISO时间与Java解析、created/claimed/approved等一致，测试覆盖实际手机序列化字段。
- [ ] 老人主动发起；一次性链接领取；未批准不能读应用清单或发任务。
- [ ] 设备/来宾凭证互不混用；跨会话、猜包名、伪核心分类、恶意标签和XSS、重复包、任意action被拒绝。
- [ ] 手机对每批任务确认；按钮拒绝、返回、Escape/对话框取消有一致拒绝结果，不永远停pending。
- [ ] 撤销立即使凭证和未开始任务无效；清理中也能撤销后续控制，不为“随时断开”设置不可解释例外。
- [ ] 超过30秒无设备心跳禁止新任务；前台/后台/断网状态显示真实，不伪在线。
- [ ] 到期、服务重启、手机重启/Activity销毁、断网重连和结果回传失败有明确恢复路径。
- [ ] pending/running/needs-confirmation与终态一致；成功和部分成功要求完整逐包结果；缺结果/未卸载不能成功。
- [ ] 对手机号/短信/私人文件/完整浏览日志不提供远程读取能力，不开放ADB或任意shell。
- [ ] 生产HTTPS、凭证不进URL query/日志、禁止跨域凭证泄露、限流/体积/路径穿越/安全头经过验证。
- [ ] 本机模拟全流程测试与真正跨设备HTTPS测试分别记录，不混称远程已上线。

## D. 广告防护
- [ ] 域名IDN/大小写/末尾点规范化；子域边界匹配；allow优先；URL/IP/通配/非法标签被拒绝。
- [ ] 广告请求的DNS NXDOMAIN保留正确ID/question；允许请求经protect且绑定真实上游网络，响应ID/question验证。
- [ ] IP/UDP长度、校验和、分片、截断、压缩问题名等异常不崩溃或越界；记录不含完整浏览数据。
- [ ] 仅虚拟DNS路由，非广告普通连接与协助网络正常；IPv6/TCP/Private DNS/DoH绕过能力明确说明，不能假全覆盖。
- [ ] 不替换现有VPN，不自动安装HTTPS证书或启用无障碍；通知/未知来源等权限入口真实可操作。
- [ ] STOP/onRevoke/onDestroy/网络变化清理FD、socket、thread、callback；旧回调不能重写active。
- [ ] 修改规则后的生效方式清楚；误拦允许名单、服务未开/失败/重启后未启均不显示防护已开。
- [ ] 通知计数不冒充广告拦截；权限引导不冒充静默撤权；不保证所有系统/应用内广告被过滤。

## E. 老人易用性
- [ ] 接近参考照片的白底蓝圈/单主操作/六大入口，非营销页面；不出现100分、无毒、永不中毒。
- [ ] 大字、至少56px触控；手机375px/横屏/200%字体无横向溢出、截断或遮挡主要操作。
- [ ] 键盘、可见焦点、读屏标签/焦点顺序、确认框焦点/取消/恢复焦点通过；减少动画有效。
- [ ] 文字对比至少4.5:1；如仅交付浅色，明确浅色策略，不声称已支持未测试深色。
- [ ] 预览、未连接、未授权、等待、失败均有下一步；老人不用理解ADB/包名才能找到操作。
- [ ] 不依赖外部字体/CDN/追踪脚本；网页无手机时明确预览且不能伪删除。

## F. 最终交付与真实设备授权
- [ ] 更新README、项目计划、API契约、能力/隐私/许可证说明、APK使用与高级权限初始化、服务HTTPS部署步骤。
- [ ] 验证记录写命令/版本/结果/证据路径/未执行事项，而不是只写“通过”。
- [ ] 先使用可丢弃测试App/模拟设备。对用户原手机真实安装、卸载、重启和改设置必须另行获得明确授权。
- [ ] 若没有真实设备/公网域名，不把所有验收项强行勾选。开发交付可以完成，但产品真机验收仍待执行。
